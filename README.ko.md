## 만드는 프로젝트

### [ilokesto](https://github.com/ilokesto)

상태, 폼, UI 프리미티브, 네트워킹을 위한 작은 TypeScript 패키지를 만듭니다.
핵심 로직은 프레임워크에 의존하지 않게, 프레임워크별 어댑터는 얇게 유지합니다.
